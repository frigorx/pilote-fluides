3. Triphasé : trois valeurs égales

Trois enroulements identiques : U1-U2, V1-V2, W1-W2.

Trois valeurs égales, à 0,2 Ω près. Entre deux enroulements différents : OL.

Une valeur différente : un défaut à chercher. OL : un enroulement coupé.

3. Un hermétique : trois broches

Ici en étoile : le pont d'étoile est à l'intérieur ; chaque mesure traverse deux enroulements.

Enroulements de 8 Ω : 2 × 8 = 16 Ω entre deux broches.

Exemple : 15,8 · 15,9 · 15,8 Ω : écart 0,1, égales.

4. Exemple résolu : bornier non repéré

1-2 = 11 Ω · 1-3 = 3 Ω · 2-3 = 14 Ω · carcasse : OL

  1. Somme : 3 + 11 = 14 Ω juste.
  2. La plus grande (2-3) : la broche absente, la 1, est C.
  3. Depuis C : la plus faible (1-3) donne R = 3 ; la plus forte (1-2) donne S = 2.
  4. Carcasse en OL : bon.
