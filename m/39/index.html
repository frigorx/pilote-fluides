Je découvre : un collage raté

1. Ce qui fait tenir un collage : la colle dissout un peu les deux faces, qui se soudent : surfaces propres, dépolies, emboîtées sans bouger.

2. Gestes fautifs : colle sur le tube seul ; tourné d'un quart de tour ; eau le soir même.

3. Plier le PVC à la flamme ? non : le PVC ne se chauffe pas ni ne se plie.

G5 : tenir et laisser dilater

Vrai ou faux ?

On peut passer le PVC à la flamme pour le plier, comme on cintre le cuivre.Faux : aucune flamme sur le PVC, qui ne se plie pas. Le piège de la leçon.
On colle deux pièces de PVC bout à bout.Faux : l'emboîture existe pour cela.
Le repère au feutre sert à contrôler l'emboîtement ou le sertissage.Vrai : après le geste, il montre si le tube a glissé.
L'acier noir convient à l'eau potable.Faux : l'acier noir est interdit pour l'eau potable.
Un collier serré à fond protège le tube.Faux : le tube bouge ; un collier serré le fait flamber.
L'élève met le réseau sous pression.Faux : le professeur seul.
Un solvant va dans la benne plastique.Faux : un solvant est un déchet dangereux, à part.
