Gare 5 — Conventions graphiques : traits, hachures, symboles

Bienvenue en gare

Un plan est écrit dans une langue codée : des traits, des hachures, des symboles — les mêmes pour tous les métiers, partout en France. Environ 2 heures. À la fin, vous saurez :

  • lire le code des traits (vu, caché, axe…) ;
  • reconnaître les matériaux à leurs hachures ;
  • repérer les symboles courants (portes, fenêtres, escalier) — et le réflexe qui sauve : chercher la légende.

Le code des traits

Le trait fort attire votre œil sur l'essentiel : ce qui existe et ce qui est coupé. Le fin habille. L'interrompu vous dit « c'est là, mais vous ne le voyez pas » (une gaine dans la cloison, une fondation).

Le réflexe : la légende d'abord

Personne ne connaît TOUS les symboles par cœur — et les cabinets d'architectes ont chacun leurs habitudes. Le plan fournit sa légende : la table de traduction de ses propres codes.

Avant de lire un plan : 1. le cartouche (gare 3) · 2. la légende · 3. le plan. Dans cet ordre. Deviner un symbole, c'est prendre un risque gratuit.

Cas pratique : lire une petite coupe

Vous venez de lire une coupe de doublage sans un seul mot d'explication : c'est toute la puissance des conventions.

Répondez à tout, votre score s'affiche en bas. Les deux dernières questions regardent vers votre métier.
