Gare 8 — Le croquis coté : dessiner à main levée

Bienvenue en gare

Jusqu'ici vous LISIEZ. Cette gare, c'est l'inverse : vous PRODUISEZ. Le croquis coté est le brouillon intelligent du chantier : rapide, à main levée, mais assez précis pour qu'un autre travaille avec. Environ 2 heures. À la fin, vous saurez :

  • appliquer la méthode en 6 étapes du croquis ;
  • respecter les proportions sans mesurer ;
  • relever les dimensions et les reporter proprement ;
  • juger votre croquis au seul critère qui compte : un tiers peut-il l'utiliser ?

Le croquis n'est pas un dessin raté : c'est un outil à part entière, avec ses règles. La première : il porte TOUJOURS ses cotes.

La méthode en 6 étapes

  • 1. Les axes — traits légers : l'ossature du croquis ;
  • 2. Les contours — la forme générale, d'un geste sûr ;
  • 3. Les détails — ouvertures, épaisseurs, points singuliers ;
  • 4. Les cotes — les dimensions UTILES d'abord ;
  • 5. La légende — noms, matériaux, repères ;
  • 6. La mention — « sans échelle », votre nom, la date.

Dans cet ordre. Celui qui cote avant d'avoir fini les contours se retrouve à écrire dans le dessin.

Les proportions : l'œil avant la règle

« Sans échelle » ne veut pas dire « n'importe quoi » : un mur deux fois plus long qu'un autre doit PARAÎTRE deux fois plus long.

Astuce : comparez tout à UNE dimension de référence (« ce mur, c'est environ deux fois celui-là »). L'œil sait faire.

Relever : mesurer avant de coter

Sur l'existant, le croquis accompagne le relevé :

  • mesurer dans les deux sens (longueur ET largeur) ;
  • contrôler une diagonale : si les diagonales d'une pièce « rectangulaire » diffèrent, elle n'est pas d'équerre — notez-le ;
  • reporter chaque mesure SUR le croquis, tout de suite — jamais de « je m'en souviendrai ».

Exemple résolu : le croquis relevé d'une porte. Axes, contours, détails, cotes reportées dans les deux sens, une diagonale contrôlée, légende, mention.

Outils du relevé : mètre ruban (≤ 10 m), décamètre, niveau, fil à plomb. Et le croquis, qui reçoit tout.

Le critère final : exploitable par un tiers

Votre croquis est bon si quelqu'un qui n'était PAS là peut, avec lui seul :

  • comprendre la forme (proportions, vues utiles) ;
  • retrouver toutes les dimensions (cotes complètes, lisibles) ;
  • savoir de quoi on parle (légende, orientation, date).

Avant de rendre un croquis, posez-vous LA question : « si je l'envoie au bureau et que je pars en week-end, peuvent-ils commander le matériel ? » Si le doute existe, une cote manque.

Le test de la gare

Répondez à tout, votre score s'affiche en bas. Les deux dernières questions regardent vers votre métier.

Terminus de la gare 8

Axes, contours, détails, cotes, légende, mention : la méthode est à vous. Le reste, c'est de l'entraînement — l'exercice vous en donne.
