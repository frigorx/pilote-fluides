Câblage virtuel
Lire la carte, poser les fils sur les bornes
🎓 Prise en main : le tutoriel Douze étapes sur l’allumage simple : colorier, repérer, poser un fil, l’aide, le contrôle, la vue réelle, les trois modes. Un quart d’heure.

Les chapitres

La manière de travailler

Trois temps, comme au TP1 Colorier les conducteurs du schéma (L1, L2, L3, N, PE) · 2 Repérer les numéros des bornes · 3 Câbler la platine, fil par fil.
Trois modesGuidé : le logiciel montre le fil à poser, vous trouvez les numéros · Aidé : dans l’ordre que vous voulez, le bouton Aide reste là · Réel : rien n’est montré, le contrôle vient à la fin, comme à l’examen.
L’aide est comptéeChaque appui sur Aide compte, chaque fil refusé aussi. Le contrôle donne un niveau de 0 à 4 : vous le recopiez sur votre feuille.
La vue réelleSur la platine, les vrais appareils à la place des symboles : mêmes repères, mêmes numéros de bornes.
