#  Révisé le 20/09/2026. La règle tient en une phrase :

#      On accepte d'être LU et CITÉ. On refuse d'être ASPIRÉ.
#
#  Il y a deux familles de robots d'intelligence artificielle, et les
#  confondre coûte cher :
#
#   · les AGENTS À LA DEMANDE (ChatGPT-User, Perplexity-User…) vont
#     chercher une page au moment où quelqu'un pose une question, et
#     affichent le lien dans leur réponse. Ce sont eux qui amènent un
#     élève ou un formateur jusqu'ici. On les accueille.
#
#   · les ASPIRATEURS D'ENTRAÎNEMENT (GPTBot, ClaudeBot, CCBot…)
#     recopient le site pour entraîner un modèle. Rien ne revient, et
#     le contenu est sous licence CC BY-NC-ND. On les refuse.
#
#  Ce fichier est une déclaration d'intention : il est respecté par les
#  acteurs sérieux, il n'arrête personne d'autre. Le blocage réel se
#  fait au niveau du réseau (Cloudflare).
# =====================================================================
