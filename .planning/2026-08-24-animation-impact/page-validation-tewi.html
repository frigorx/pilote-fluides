5 illustrations animées à relire

Station « Le TEWI » — les 5 animations proposées

À gauche l'illustration actuelle (fixe), à droite la version animée proposée. L'animation rejoue le scénario de la narration, puis l'image reste stable quelques secondes avant de reboucler. À l'arrêt (impression, PDF), la version animée montre exactement l'image finale complète.

Écran 1 — Le TEWI : une balance à deux plateaux

svg/balance-tewi.svg

Scénario (narration existante) : les deux plateaux se chargent tour à tour ; aucun n'est plus lourd par principe — la balance reste à l'équilibre, c'est le cas réel de chaque machine qui décide.

AVANT — fixe

APRÈS — animé

Ce qui change : les deux plateaux se chargent l'un après l'autre, la balance reste à l'équilibre, puis la formule s'affiche.

Écran 2 — La part directe, en détail

svg/part-directe.svg

Scénario (narration existante) : « Suivez la chaîne de gauche à droite » : machine qui fuit × PRP du fluide = part directe en équivalent CO₂.

AVANT — fixe

APRÈS — animé

Ce qui change : la chaîne se déroule bloc par bloc, une goutte tombe de la machine pendant la première étape.

Écran 3 — La part indirecte, en détail

svg/part-indirecte.svg

Scénario (narration existante) : même principe de chaîne : énergie consommée × durée de vie → réseau électrique du pays → part indirecte en équivalent CO₂.

AVANT — fixe

APRÈS — animé

Ce qui change : la chaîne se déroule bloc par bloc et l'aiguille de l'horloge fait un tour complet — les années de service passent.

Écran 4 — Piège n°1 : la machine gourmande

svg/piege-machine-gourmande.svg

Scénario (narration existante) : fluide propane PRP 3, peu de fuites : direct faible ; compteur poussé dans le rouge : indirect fort ; la balance penche côté indirect.

AVANT — fixe

APRÈS — animé

Ce qui change : l'aiguille du compteur monte dans le rouge, puis la balance — d'abord à plat — penche nettement côté indirect.

Écran 5 — Piège n°2 : la machine qui fuit

svg/piege-machine-qui-fuit.svg

Scénario (narration existante) : le miroir : R-404A qui fuit régulièrement : direct fort ; machine efficace, aiguille dans le vert : indirect faible ; la balance penche côté direct.

AVANT — fixe

APRÈS — animé

Ce qui change : les gouttes s'échappent du groupe, l'aiguille reste dans le vert, puis la balance penche côté direct — le miroir exact du piège n°1.

Les autres écrans de cette station restent fixes (comparaison côte à côte, carte d'identité, raisonnement, bilan) : l'animation n'y apporterait rien. Réseau Législation inerWeb — document de travail, non diffusé.
