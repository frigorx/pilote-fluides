# Signaler un problème de sécurité

Ce site est un projet pédagogique statique (GitHub Pages) : pas de compte,
pas de base de données, pas de collecte nominative. Un problème de sécurité
reste possible — contenu chiffré du coffre documentaire, script du moteur,
en-têtes, dépendances de build.

**Canal de signalement :**

- courriel : **inerweb.fh@gmail.com** (le contact public du projet, voir `LICENCE.md`) ;
- ou une [issue GitHub](https://github.com/frigorx/pilote-fluides/issues) —
  publique : n'y mettez **aucun détail exploitable**, demandez-y simplement
  un contact.

**Engagement :** accusé de réception sous 7 jours ; pas de représailles
contre un signalement de bonne foi ; merci de laisser un délai raisonnable
de correction avant toute divulgation.

**Périmètre :** ce dépôt et le site https://inerweb.fr. Les applications
sœurs (inerWeb Fluide, outils) ont leurs propres dépôts.

**Hors périmètre :** le contenu pédagogique lui-même (une erreur de cours
se signale par issue ordinaire) ; les fichiers chiffrés du coffre sont
publics par construction — leur confidentialité repose sur la phrase
d'accès, pas sur le secret du fichier (voir `documents.html`).
