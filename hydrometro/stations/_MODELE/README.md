# Modèle de station indépendante

Ce dossier ne contient pas encore de station développée. Il matérialise seulement la frontière
d’intégration décrite dans `../../CONTRAT-STATION.md`.

Lorsqu’une station entre en développement :

1. copier `_MODELE` sous son identifiant stable ;
2. ajouter son `manifest.json` ;
3. développer le module hors ligne dans ce dossier ;
4. exécuter sa QA indépendamment ;
5. ne la raccorder au réseau qu’après validation de son contrat.
